## 📖 產品規格書 (Product Requirements Document - PRD)

### 1. 產品背景與核心價值
大學生與年輕族群在日常生活中經常面臨「月底吃土」、「衝動消費」、「記帳容易半途而廢」三大痛點。常見記帳 App 操作繁複且冷冰冰，缺乏心理回饋機制。
**「柴犬理財守護員」** 融合了「遊戲化寵物陪伴」與「極簡記帳工具」，透過生動的柴犬表情回饋、親密度養成系統、以及針對衝動消費的「理智滅火器」，讓理財不再是沉重的負擔，而是一場溫暖的守護之旅。

### 2. 系統架構與功能模組

#### 模組 A：柴犬情感守護系統 (Shiba Emotional Companion)
1. **動態視覺表情**：
   - `happy`（安全期）：當支出 $\le 70\%$ 預算時，搖尾微笑，語氣激勵。
   - `warning`（警戒期）：當支出達 $71\% \sim 99\%$ 預算時，立耳警惕，提醒審慎花費。
   - `danger`（超支期）：當支出 $\ge 100\%$ 預算時，垂耳沮喪，發出警示。
   - `petting`（互動撒嬌）：點擊柴犬觸發，雙眼瞇起，臉頰泛紅，頭頂冒出愛心動畫。
2. **親密度養成（Affection Points）**：
   - 每次點擊柴犬或記上一筆帳，親密度增加，累積滿額即提升親密等級（如：Lv.1 初識柴 $\rightarrow$ Lv.2 好夥伴 $\rightarrow$ Lv.3 靈魂伴侶）。
3. **理智滅火器（Impulse Purchase Snuffer）**：
   - 提供「買手搖飲前」、「想獎勵自己」、「月底焦慮」、「真有必要嗎？」四種常見衝動消費情緒按鈕，點擊後柴犬給予理智又溫柔的心理建設。

#### 模組 B：極簡記帳與預算監控 (Fast Ledger & Budget Control)
1. **本月預算監控**：即時顯示總預算、已支出、本月結餘與百分比，預算條根據百分比動態平滑轉變顏色（綠 $\rightarrow$ 橘 $\rightarrow$ 紅）。
2. **快捷記帳按鈕（Quick Chips）**：預置大專生最高頻的支出項目（早餐 $65、午餐 $120、拿鐵 $85、珍奶 $60、捷運 $30、超商 $100），一鍵填入即時送出。
3. **語音智慧輸入**：支援 Web Speech API 語音辨識，說出「午餐 一百元」自動解析金額與項目。
4. **收支列表管理**：
   - 支援依類別（全部/飲食/交通/娛樂/購物/其他）快速篩選。
   - 每一筆帳目具備 **「編輯」** 與 **「刪除」** 功能，編輯時彈出對話框即時修正，刪除具備防誤觸確認。

#### 模組 C：資料安全與本機備份 (Data Privacy & Portability)
1. **LocalStorage 持久化**：所有數據儲存在使用者瀏覽器本機端，不經任何後端伺服器，100% 確保財務隱私。
2. **CSV 報表匯出**：自動生成包含 UTF-8 BOM 的 CSV 檔案，可直接於 Microsoft Excel 或 Google 試算表開啟，絕不產生亂碼。
3. **JSON 完整備份與還原**：支援將全部帳目、預算、親密度匯出成 `.json` 檔案保存，更換電腦或瀏覽器時可隨時一鍵導入還原。

#### 模組 D：純代碼 Web Audio 音效引擎 (Zero-dependency Synthesizer)
- 採用瀏覽器原生 Web Audio API 即時運算音頻振盪器（OscillatorNode）：
  - 記帳成功：金幣入袋清脆雙音階（880Hz $\rightarrow$ 1760Hz）。
  - 摸頭撒嬌：可愛溫暖汪汪短音（440Hz 柔和顫音）。
  - 刪除記錄：低音降頻警示（300Hz $\rightarrow$ 150Hz）。
  - 支援右上角喇叭按鈕隨時一鍵靜音/開啟。

### 3. 資料結構規範 (Data Schema)

#### (1) 交易紀錄結構 (Transaction Item)
```typescript
interface Transaction {
  id: string;          // 唯一時間戳標籤，例如 "tx_1711200000000"
  type: 'expense' | 'income'; // 交易類別
  category: 'food' | 'transport' | 'entertainment' | 'shopping' | 'other';
  amount: number;      // 金額 (正整數)
  desc: string;        // 描述說明
  date: string;        // 日期 ISO 格式 "YYYY-MM-DD"
  createdAt: number;   // 建立時間戳記 (毫秒)
}
```

#### (2) 系統設定與親密度結構 (System State)
```typescript
interface AppState {
  budget: number;      // 本月預算 (預設 8000)
  affection: number;   // 柴犬親密度點數 (預設 12)
  soundMuted: boolean; // 是否靜音 (預設 false)
}
```

#### (3) 本機儲存鍵值 (LocalStorage Keys)
- `shiba_records_v2`：儲存 `Transaction[]` 陣列 JSON 字串。
- `shiba_budget_v2`：儲存每月總預算數值。
- `shiba_affection_v2`：儲存柴犬親密度累計點數。

## 🤖 Vibe Coding 與 AI 討論迭代紀錄 (AI Iteration Log)

本專案全程落實 **「將想法說清楚 → 與 AI 討論規格 → 利用 Vibe Coding 實作 → 反覆微調優化」** 之歷程，以下為 5 個關鍵迭代階段之真實對話提示詞與演進紀錄：

### 階段一：發想核心價值與特色定位
- **使用者 Prompt**：
  > 「我想做一個大學生用的記帳網頁，但一般的記帳軟體很無聊，大家記了三天就放棄。我想要加入一隻柴犬當守護員，當使用者花太多錢時柴犬會難過，還可以用摸頭來互動。請幫我設計一個符合 Vibe Coding 精神且能放在單一 index.html 裡的架構草案。」
- **AI 建議與回饋**：
  - 建議不要依賴外部圖片圖檔，避免圖片外部載入失敗或 GitHub Pages 破圖，改採**純 SVG 向量代碼**繪製柴犬表情，並用 CSS 控制眼皮、腮紅與耳朵。
  - 將記帳狀態與情緒關聯起來：支出低於 70% 開心、70%～100% 警戒、超支時沮喪。
  - 增加「親密度」計分機制，給予持續記帳的正向激勵。

### 階段二：建立第一版原型與基本功能
- **使用者 Prompt**：
  > 「請幫我寫出第一版 HTML。要有預算設定、收入/支出記帳表單、當前花費進度條，以及明細列表。我希望能儲存在 localStorage，重開瀏覽器不會消失。」
- **AI 實作與產出**：
  - 產出基礎表單、CSS Grid 卡片版面、以及 LocalStorage 讀寫邏輯。
- **測試發現問題**：
  - 每次記手搖杯或午餐都要自己打字輸入「午餐」、「120」，太花時間，記帳阻力依然很高。

### 階段三：體驗優化——快捷按鈕與理智滅火器
- **使用者 Prompt**：

- **AI 建議與優化**：
  - 在記帳表單頂部加入 6 顆「高頻快捷 Chip 按鈕」，點擊直接帶入類別與金額並完成新增。
  - 設計「衝動消費滅火器」對話框，預設「買手搖飲前」、「想獎勵自己」、「月底焦慮」等情境，點擊後由柴犬吐出幽默而中肯的勸退金句。

### 階段四：情感互動深化——摸頭系統與純代碼音效
- **使用者 Prompt**：
  > 「柴犬目前看起來還是有點生硬，我希望能摸摸牠，點牠時會搖晃、飄愛心，親密度會增加。另外可以有記帳聲音嗎？但不要外連 mp3，因為常常外連會 404。」
- **AI 實作與演進**：
  - 為 SVG 柴犬加入 `@keyframes petBounce` 與動態注入浮動愛心元素。
  - 利用原生 **Web Audio API**，純代碼即時合成 880Hz 金幣音效、狗狗叫聲與低頻警示音，完美解決外部音檔丟失問題。

### 階段五：功能完整性補強——帳目編輯、CSV/JSON 匯出與無障礙
- **使用者 Prompt**：

   - 點擊快捷按鈕「🍱 午餐 $120」，系統即刻發出清脆金幣聲，並自動新增至明細。
   - 觀察預算進度條與餘額變化，柴犬親密度上升。
2. **柴犬互動體驗**：
   - 用滑鼠連續點擊「柴犬頭部」，柴犬會害羞瞇眼、臉頰泛紅、頭頂飄出紅色愛心，並發出可愛短叫聲。
3. **衝動滅火體驗**：
   - 點選理智滅火器中的「🧋 買手搖前」按鈕，立即獲取柴犬的溫暖理財建議。
4. **帳目修改與防呆**：
   - 點擊任一筆帳目旁的「✏️ 編輯」，修改金額後點擊儲存，儀表板與圖表即時聯動重算。

   - 點擊「匯出 Excel (CSV)」，系統將下載 `柴犬記帳報表_YYYY-MM-DD.csv`，雙擊即可用 Excel 檢視。
